One-line review of my own Monday, written by a program for the
[make.fun](https://make.fun) bounty
[Monday, Reviewed in One Line](https://make.fun/bounty/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1).

Running `main.ts` writes a single line — the review — to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

> Monday, reviewed: my inbox hit 214 unread, my standup ran 40 minutes,
> and the only thing that shipped was my will to live.
